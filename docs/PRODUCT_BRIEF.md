# Product brief

A local-first desktop app for recording meetings, transcribing them on-device, and generating searchable notes without sending audio to the cloud by default.

## Problem

Professionals handling sensitive conversations need meeting notes, search, and recall, but cloud note-takers create privacy, compliance, and trust concerns.

## Solution

A macOS desktop app that:

- captures system audio and microphone audio locally,
- transcribes with a selectable local model,
- summarizes locally,
- stores audio encrypted on-device,
- provides fast search over transcripts,
- offers optional self-hosted sync later.

## Primary users

Lawyers, therapists, consultants, founders, journalists, privacy-sensitive teams.

## Value proposition

- No bot joins the meeting.
- Audio stays local by default.
- Transcripts are searchable immediately.
- Users can choose the model that fits their hardware and language needs.

## Non-goals for v1

No team collaboration, browser extension, calendar automation, cloud sync by default, or live meeting assistant.

## Product principles

Local-first. Explicit consent UX. Minimal setup. Reliable transcription over cleverness. Easy export. Transparent model selection.

## v1 success criteria

- User can record system audio and mic on macOS (live capture is the next wave; fixture path is green today).
- User can transcribe locally.
- User can search past meetings.
- User can export transcript and summary.
- App feels fast, stable, and private.
